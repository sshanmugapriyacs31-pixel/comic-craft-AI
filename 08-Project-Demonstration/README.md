# 8. Project Demonstration Phase

## Project: ComicCraft – AI Comic Story Creator

The demonstration phase presents the completed ComicCraft application and explains how the system works.

### Demonstration Steps

1. Open the ComicCraft application.
2. Enter a story prompt.
3. Enter the character name.
4. Select the setting.
5. Select the tone.
6. Select the art style.
7. Generate the comic.
8. Display the generated comic panels.
9. Show the narration and dialogue.
10. Demonstrate the PDF export feature.

### Features Demonstrated

* User-friendly comic creation interface
* AI-generated comic outline
* AI-generated narration and dialogue
* Comic illustrations
* Comic preview
* PDF export

### Expected Outcome

The demonstration shows how ComicCraft transforms a simple user idea into an AI-generated comic story with illustrations and downloadable output.
